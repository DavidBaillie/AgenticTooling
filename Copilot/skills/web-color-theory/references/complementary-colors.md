# Complementary Colors

## Definition

Complementary colors sit opposite one another on the color wheel. They create the strongest basic hue contrast and are commonly modeled as a base hue `H` paired with `H + 180` degrees.

## Formula

For a base hue `H`:

- Base: `H`
- Complement: `H + 180`

Wrap values above 360 back into the 0 to 360 range.

## Character

- High-energy, vivid, and attention-grabbing.
- Useful for separating a primary action from its surrounding field.
- Can feel noisy, harsh, or visually competitive when both hues are equally saturated and equally prominent.

## Web Use

- Let one hue dominate the interface and use its complement as a controlled accent.
- Reduce the complement's chroma or area when the page feels loud.
- Use lightness contrast and neutral surfaces to create hierarchy before increasing saturation.
- Avoid pairing fully saturated complementary colors for large text blocks or large adjacent surfaces.
- Test text and icon contrast independently; perceived hue contrast does not replace measurable contrast.

## Example Brief

> Build a complementary palette around deep blue and a warm orange accent. Keep blue dominant across navigation and surfaces, use orange only for primary actions and selected states, and provide accessible text colors for both.

## Common Mistake

Do not split the page into equal areas of two fully saturated complements. This often causes vibration at edges and makes the interface feel unstable. Use proportion, lightness, and neutral space to control the relationship.
