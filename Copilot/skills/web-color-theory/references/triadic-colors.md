# Triadic Colors

## Definition

Triadic colors are three hues spaced evenly around the color wheel. In a hue-based model, they are separated by approximately 120 degrees.

## Formula

For a base hue `H`, use:

- `H`
- `H + 120`
- `H + 240`

Wrap values above 360 back into the 0 to 360 range.

## Character

- Balanced, lively, and more varied than an analogous palette.
- Provides three distinct hue families without the direct tension of a complementary pair.
- Can become playful or overly loud when all three colors are equally saturated and equally large.

## Web Use

1. Select one dominant hue for the main brand or action.
2. Give the second hue a supporting structural role.
3. Reserve the third hue for a small accent, illustration, chart category, or meaningful state.
4. Use lightness and chroma differences to establish hierarchy.
5. Use semantic state colors carefully. A triadic palette should not override established expectations for success, warning, or danger.

## Example Brief

> Create a triadic palette based on blue. Use blue as the dominant interface color, a softened yellow-green for supporting surfaces, and a restrained red-orange for small accents. Keep large surfaces low-chroma and verify text contrast.

## Common Mistake

Do not give all three hues equal visual weight by default. The geometric relationship supplies variety; hierarchy still needs to come from area, lightness, chroma, typography, and spacing.
